# Client Side Browser Image Compression

This example demonstrates how to perform image compression directly within the user's browser, without uploading any files to a server. It utilizes the HTML Canvas API to load and re-encode images with a specified quality, addressing privacy concerns and improving performance by keeping all processing client-side. Users can select an image, adjust the compression quality, and see the size reduction in real-time.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
3. Select an image file using the 'Choose File' button and click 'Compress Image'.
